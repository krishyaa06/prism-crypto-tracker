## ⚡ Overview
**Prism Protocol Crypto HUD** ek modular aur responsive cryptocurrency dashboard hai jo real-time market data track karta hai aur local browser storage ke zariye portfolio valuation compute karta hai.

### Features
- 🌌 **Ambient Canvas Simulation**: Background matrix dots rendering.
- ⚡ **Real-Time Market Telemetry**: Public API se direct market updates.
- 💼 **Encrypted Local Storage**: Browser me secure offline holdings persistence.
- 📱 **Mobile Optimized**: Termux aur mobile viewports ke liye fluid UI.
